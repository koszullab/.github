# Getting help

- **How to use a tool:** its documentation, linked from its repository's README and *About* box.
  Every tool also answers `--help`, for itself and for each of its commands.
- **Something does not work:** search the repository's issues, open and closed, then open one with
  the *Bug report* form. Give the version, how you installed the tool, the command, and its log: the
  `<sample>.<tool>_<timestamp>.log` the command wrote beside its outputs, or what it printed.
- **A question, or an idea:** open an issue with the *Feature request* form, or a discussion where
  the repository has them.
- **A security problem:** report it privately, as the [security policy](https://github.com/koszullab/.github/blob/main/SECURITY.md) says.
