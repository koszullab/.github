# koszullab/.github

The conventions of the project's repositories, and the default community files of koszullab's.

- [`CONVENTIONS.md`](CONVENTIONS.md): how a repository of the project is laid out, built, tested,
  documented and released.
- [`MIGRATION.md`](MIGRATION.md): what each repository still changes to follow them. It goes once the
  last of those pull requests has merged.
- The community files GitHub shows in every repository of koszullab that has none of its own:
  the [code of conduct](CODE_OF_CONDUCT.md), the [security policy](SECURITY.md), [getting help](SUPPORT.md),
  [contributing](CONTRIBUTING.md), the [issue forms](.github/ISSUE_TEMPLATE) and the
  [pull-request template](.github/pull_request_template.md).
